# i-e-project

Project page for the startup course (I&E): presentation, slides, application, video and code of the principle. Every new version is added to the page, and older versions stay on it as archives.

**Live page:** https://sanixto.github.io/i-e-project/

## Structure

```
index.html          page content
src/css/style.css   styles (light/dark theme)
src/js/theme.js     theme switcher
```

## Adding a new version

1. Put the file in the repo (`slides/`, `video/`, `code/`), or for the app, use its URL.
2. In `index.html`, copy the last `<li>` of the section, then update the link, date and submission number.
3. Never delete old rows: they are the archive.
